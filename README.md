# 📦 Inventory Management

> A web-based inventory and stock management dashboard — built with vanilla HTML, CSS, and JavaScript. Track products, manage stock levels, and view supply chain data in a clean, responsive UI.

## ✨ Features

- 📋 **Product Listing** — View all inventory items in a structured table/card layout
- 🔍 **Search & Filter** — Quickly find items by name, category, or stock status
- ➕ **Add / Edit / Delete** — Full CRUD operations on inventory items
- 📊 **Stock Status Indicators** — Visual low-stock and out-of-stock warnings
- 📱 **Responsive Design** — Works across desktop and mobile screens

## 🚀 Getting Started

### No dependencies required — runs directly in any browser.

```bash
# 1. Clone the repository
git clone https://github.com/akashcyber02/inventory-management.git
cd inventory-management

# 2. Open in browser
open index.html

# Or use VS Code Live Server:
# Install "Live Server" extension → Right-click index.html → "Open with Live Server"
```
